迪克的黑调 —— 使用指南
==================================================

一句话：提前把要「现场手写」的代码录好，台上点一下空行、随便乱按键盘，
编辑器里就会像真人一样一个字一个字打出正确的代码。


一、安装
--------------------------------------------------
1. 打开 VS Code，按 Cmd+Shift+P（Windows 是 Ctrl+Shift+P）。
2. 输入并运行「Extensions: Install from VSIX...」。
3. 选择本文件夹里的 dick-black-tune-x.x.x.vsix（版本号最大的那个，会覆盖旧版本）。
4. 装完后再按 Cmd+Shift+P，运行「Developer: Reload Window」（重新加载窗口）。
   每次装新版本都要重新加载一次，否则改设置可能报错。
5. 以前装过旧名字「演示打字机」（zhizhong.demo-typer）的话，在扩展列表里把它卸载，
   不然两个会同时接管键盘。旧的设置和工作区里的 .demo-typer 目录会自动搬到新名字下。
6. 左边活动栏会多出一个「键盘」图标，点开就是「迪克的黑调」面板。
   所有操作都能在这个面板里点，不需要记快捷键。

从源码打包（GitHub 上下载的源码没有 .vsix）：
   npx @vscode/vsce package --no-dependencies
   会在当前文件夹生成 dick-black-tune-x.x.x.vsix。


二、录制（演示前准备）
--------------------------------------------------
1. 打开要演示的文件。
2. 用鼠标选中要「现场手写」的那段代码（整行选中即可）。
   按住 Option（Windows 是 Alt）拖选，可以一次选中好几段。
3. 点面板里的「● 录制选中代码」。
   - 代码会被存起来，原来的位置只留一个空行，这就是台上要点的地方。
   - 一次选了好几段，每段各存成一个片段。
   - 第一次录制时会自动备份原文件，以后可以一键恢复。
4. 录好的内容存在工作区的 .dick-black-tune/snippets.json 里。


三、台上演示
--------------------------------------------------
1. 先切到英文输入法。
2. 打开面板顶部的「演示模式」开关（或按 Cmd+Option+D / Ctrl+Alt+D）。
3. 讲到写代码时，用鼠标点一下要写代码的那个空行，开始随便敲键盘。
   插件按这个空行上下的代码认出该打哪一段。
4. 一段打完后，继续敲也不会多出字。点下一个空行，接着敲就是下一段，顺序随意。
5. 这个文件的片段全部打完后，键盘自动恢复正常，可以正常改代码、运行程序。
6. 台上可以把侧边栏收起来，观众看不到面板，不影响使用。
7. 底栏「行、列」左边只显示一个进度数字（比如 14%），投屏时不显眼。

看起来像真人的地方：
- 多数时候一键一个字，偶尔连出两个；间隔随机，整体快慢会慢慢变化，单词之间偶尔停顿。
- 按得慢字就出得慢，手一停字就停。
- 会弹出编辑器自己的代码补全列表；长单词有时会像按 Tab 一样一下补完。
- 打左括号、左引号时右边自动补上；换行时缩进一起出现。


四、中途暂停、接着打
--------------------------------------------------
- 想停一下：按 Esc。已经打出来的保留，底栏数字前出现暂停图标。
- 光标没动：再按任意键就接着打。
- 点到别处正常打字也可以，之后点回这一段（停下的位置，或它下面的空行）再按键，接着打。
- 关掉了演示模式、重新加载了窗口、或者中间先打了别的片段：
  点回这一段附近再按键，也会从上次打到的地方接着打，不会重新另起一份。
- 如果那里的内容被打乱了（和录制的对不上），会先自动清掉，再从头打这一段。


五、代码里的中文怎么打
--------------------------------------------------
在面板「打字设置」→「代码里的中文」里三选一：

1. 停下来，我用输入法打（默认）
   - 打到中文时插件停下来，光标处出现灰色提示文字（要打的内容）。
   - 切到中文输入法照着打，打完一定要切回英文再按键，后面的代码才接着出来。
   - 打错字、记错、多打少打都没关系：切回英文按第一下时，这一行会自动纠正。

2. 模拟拼音输入法
   - 乱按时先打出带下划线的拼音（如 ce'shi'ji），弹出仿真的候选条，再上屏成汉字。
   - 候选条按真实词频列出 7 个候选（如「测试 侧室 侧视 测时 …」）。
   - 候选条样式：跟随系统 / macOS / 微软拼音（Win10）。
   - 候选条颜色：跟随系统 / 浅色 / 深色。
   - 候选条大小不跟着 VS Code 缩放（Cmd + / Cmd -）变化，和真的系统输入法一样。
     需要打开过一次侧边栏面板，插件才能知道当前缩放。

3. 插件直接打出
   - 中文和其它字符一样直接出现。


六、彩排和整理
--------------------------------------------------
面板「当前文件」区：
- ↺ 重置：删掉已经打出来的代码（打了一半、打乱了的也会清掉），回到演示前，马上可以再练。
- ⤓ 全部填回：把所有代码一次性填回文件，方便运行完整程序。
- 文件名右边的「⋯」：
  - 恢复原文件：回到第一次录制之前的样子，一字不差。
  - 打开配置文件：snippets.json。
  - 删除全部片段：可以选择先恢复原文件再删除。

每个片段一张卡片，左边编号的颜色表示状态：
  灰 = 待打　蓝 = 正在打　橙 = 打了一半　绿 = 已在文件里
卡片上的按钮：
- 定位：跳到这一段在文件里的位置。
- 预览：看这一段的代码。
- 填入 / 清空：单独补上或删掉这一段。
- 右边「⋯」：改名、编辑代码（文件里的也一起改）、上移、下移、删除。


七、打字设置（面板里点开）
--------------------------------------------------
- 每按一次键出字：默认「多数 1 个，偶尔 2 个」；调到 1 就是严格一键一字。
- 字与字的间隔：默认约 35 毫秒，实际会随机浮动。
- 弹出代码补全：开关。打开后还有两个滑块：
  - 选补全前的停顿：补全列表弹出后停多久再「按 Tab」一下补完（默认约 300 毫秒，0～1500）。
  - 一下补完的频率：长单词有多大概率用补全一下补完（默认 40%，0～100%）。
- 代码里的中文：见第五节。


八、快捷键（面板里点开「快捷键」）
--------------------------------------------------
默认：
- 开关演示模式　　　　Cmd+Option+D（Windows：Ctrl+Alt+D）
- 暂停正在打的这一段　Esc（只在正在打时有效）
- 录制选中代码　　　　Cmd+Option+R（Windows：Ctrl+Alt+R）
- 重置 / 全部填回 / 恢复原文件 / 删除全部片段：默认没有，可以自己设

修改方法：点那一行的「修改 / 设置」，会打开 VS Code 的键盘快捷方式，
双击那一行、按下想要的组合键、回车。面板里会自动更新。


九、换电脑（比如演示用 Windows 电脑）
--------------------------------------------------
1. 在那台电脑上安装同一个 .vsix。
2. 把这台电脑上工作区里的 .dick-black-tune/snippets.json，复制到那台电脑上
   同一个工作区的 .dick-black-tune/ 里（本机如果有 presets/ 备份，也可以从那里复制）。
3. 打开演示文件，面板里就能看到这些片段。


十、注意事项
--------------------------------------------------
- 演示前先切到英文输入法（只有插件停下来等你打中文时才切中文）。
- 和 Vim 这类也接管键盘输入的插件冲突，演示时先禁用它们。
- 只在 VS Code 里有效，PyCharm 等其它编辑器里用不了。
- 演示前完整彩排一遍：打一遍 → 重置 → 再打一遍。
- 装了新版本记得重新加载窗口。
